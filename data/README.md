# 公开数据说明

本目录包含匿名化逐图结果及汇总性参照，二者具有不同的复核层级。JSON 使用 UTF-8；整数分类标签 `0`、`1` 分别对应数字 `7`、`1`。

## 逐图数据

`holdout_predictions.json` 包含全部 200 张独立测试图片：

| 字段 | 含义 |
|---|---|
| `sample_id` | 发布用匿名标识，不表示源图片索引或执行顺序 |
| `label` | 测试标签 |
| `qpu_original_head` | 实机特征经原分类头生成的预测 |
| `qpu_calibrated` | 实机特征经监督校准与固定聚合生成的预测 |
| `ideal_calibrated` | 精确无噪声特征经对应校准规则生成的预测 |

这些记录来自实验保存的逐图预测，不是按汇总准确率人工构造。匿名化仅改变标识及行顺序，保留标签、预测和配对关系；不包含图片、量子计数、连续特征或分类器系数。

`temporal_predictions.json` 的 80 条记录通过相同匿名标识连接原测试集：

| 字段 | 含义 |
|---|---|
| `sample_id`、`label` | 对应测试图片及标签 |
| `initial` | 初始评估的监督校准预测 |
| `session1_frozen`、`session2_frozen` | 两时段使用原校准的预测 |
| `session1_refitted`、`session2_refitted` | 用相同校准图片的新测量重新拟合后的预测 |

该文件不是额外 80 张新图，也不能将两个时段解释为新增 160 个独立样本。分析程序校验其标签及初始预测与 200 图数据一致。

## 汇总与研究定义

- `benchmark_reference.json`：四项公开任务的 LQCloud 与本地模拟汇总，以及标为图形读取近似值的 IonQ 文献结果；文献条目没有逐图预测。
- `study.json`：任务、标签映射、校准与测试样本数、统计规则及条件性敏感性汇总。敏感性条目不由离散预测重新估计。
- `manifest.json`：上述四项输入的 SHA256。完整性校验不认证未公开的原始采集记录。

公开数据不包含同协议的 IonQ 新图实机测量、设备型号、实际布局、编译与采样配置、任务身份或凭据。
